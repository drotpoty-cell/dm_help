# FEATURES.md — Полный мануал по возможностям "GM's Second Brain"

Этот документ описывает продукт с точки зрения ГМа-пользователя: что можно сделать, где
это находится, и как это работает "под капотом" ровно настолько, насколько нужно, чтобы
не удивляться поведению интерфейса. Для архитектурных причин и истории решений — см.
`PROJECT_MAP.md`.

---

## 1. Общая идея

Один аккаунт → несколько **кампаний** (`hub/`) → внутри каждой кампании — вся "вторая
память" мастера: карта мира, персонажи, враги, локации, квесты, лут, фракции, бестиарий,
календарь и погода, боевой трекер, генератор текста через ИИ.

Инструмент однопользовательский: рассчитан на одного ГМа, ведущего свои кампании с одного
или нескольких своих устройств (не на совместное редактирование несколькими людьми
одновременно).

## 2. Вкладки верхнего уровня

После открытия кампании (`hub/[id]`) доступны 6 вкладок (переключатель — в шапке/сайдбаре
навигации):

| Вкладка | Что показывает |
|---|---|
| **Мастер** (`dashboard`, вкладка по умолчанию) | Главный "рабочий стол" для игры за столом: карта (мировая или тактическая — в зависимости от того, что сейчас открыто) + одновременно плавающие поверх неё виджеты календаря и погоды. Если открыта тактическая карта — там же сам всплывает виджет боя. Это единственная вкладка, где всё нужное для ведения сессии видно сразу, без переключений. |
| **Архив** (`archive`) | Полноэкранный браузер вообще всех сущностей кампании: герои, персонажи, массовка, враги, бестиарий, локации, квесты, лут, события, фракции. Поиск по названию, создание новой записи одной кнопкой, счётчик записей на каждой категории. |
| **Карта** (`map`) | Та же мировая/тактическая карта, что и на "Мастере", но без виджетов календаря/погоды поверх — для сосредоточенной работы с самой картой (расстановка узлов, рисование маршрутов, калибровка боевой сетки), когда лишние панели только мешают. |
| **Сюжет** (`story`) | Полноразмерный редактор глав истории кампании с поддержкой @упоминаний (см. ниже). |
| **Календарь** (`calendar`) | Полноразмерная версия календаря: текущий день/час, прокрутка времени вперёд. |
| **Погода** (`weather`) | Полноразмерная версия погоды: текущие условия, климат кампании, генерация прогноза на несколько дней вперёд. |

Слева на всех вкладках остаётся узкая колонка **CockpitSidebar** — быстрый доступ к
сущностям и перетаскивание карточек локаций прямо на карту мира (drag-n-drop, см. ниже).
Это не дублирует Архив: сайдбар — для быстрых действий во время игры, Архив — для
просмотра/редактирования и наведения порядка в базе данных кампании.

## 3. Мультимировая система

ГМ может вести несколько независимых миров/кампаний **в рамках одного браузера**:
переключатель миров хранит состояние каждого мира отдельно (сущности, карта, календарь,
погода, сюжет, бой) и подгружает нужный набор данных при переключении. Это чисто
локальный механизм — облачная синхронизация с Supabase работает поверх него отдельно для
каждой кампании (см. раздел 8), поэтому переключение миров не "путает" данные между
устройствами.

Некоторые настройки — **личные настройки браузера ГМа**, а не часть кампании, поэтому они
не сбрасываются при переключении мира:
- режим отображения "ГМ / Игрок" (`displayMode`, см. раздел 10);
- ширина панели инспектора (см. раздел 9);
- какая кампания открыта последней.

## 4. Библиотека сущностей и Архив

12 категорий сущностей, каждая — со своей формой редактирования:
`героев, персонажей (именных NPC), массовку, врагов, бестиарий, локации, квесты, лут,
события, фракции`, плюс служебная категория `secrets` (см. ниже — пока без своего UI).

Для персонажей "важный NPC" отмечается флагом — так в интерфейсе можно отличить ключевую
фигуру сюжета от случайного встречного.

Для любой категории одинаково работают: создание записи (кнопка "+" в Архиве или в
сайдбаре), открытие карточки в инспекторе, удаление (с подтверждением через тост, а не
блокирующее системное окно — см. раздел 12).

**Известная незавершённая функция:** категория `secrets` (заметки, которые ГМ не должен
случайно показать игрокам) в типах и хранилище уже есть, но своей формы редактирования и
кнопки создания в интерфейсе пока нет. Также `secrets` намеренно исключены из системы
@упоминаний — на случай, если ГМ случайно упомянет секрет в тексте, который увидят игроки.

### Универсальная картинка сущности

В инспекторе любой сущности есть один и тот же блок загрузки изображения — работает
одинаково для героя, врага, лута, квеста и т.д. Для локаций эта же картинка — это `mapImage`,
то есть ровно то изображение, которое уже показывает узел на мировой карте и (при
отсутствии кастомного боевого фона) автоматически становится фоном тактической карты
(см. раздел 7).

## 5. Мировая карта

Карта мира — бесконечный канвас (`reactflow`): узлы-локации, соединённые маршрутами
(рёбрами с указанием времени в пути в днях/часах).

**Как добавить локацию на карту:**
- клик по карточке локации в панели "Локации из Архива" в сайдбаре — добавляет узел на
  карту в позицию по умолчанию;
- **настоящий drag-n-drop** — берёте карточку локации мышью и бросаете её точно в нужное
  место канваса; во время перетаскивания карточка в сайдбаре гаснет (не двигается), а её
  "тень" следует за курсором. Если отпустить курсор за пределами канваса — узел не
  создаётся.

**Клик по узлу локации** — "провал" в тактическую (боевую) карту этой локации (если её
ещё не было — создаётся новая пустая боевая карта).

**Скорость и точность фона узла:** пока изображение локации грузится, узел показывает
анимированный шиммер-скелетон вместо резкого "прыжка" картинки — устраняет моргание при
первом появлении узла на экране.

**Расчёт времени в пути:** если у ГМа включена погода (не режим "выключено"), плохие
погодные условия (дождь/снег/гроза/туман/буря/вьюга) автоматически удлиняют время в пути
партии между связанными локациями (умножение на 1.5–2×) — при перемещении партии время
кампании сдвигается вперёд соответствующим образом.

## 6. Тактическая (боевая) карта

Открывается провалом в локацию с мировой карты. Своя сетка (размер клетки настраивается
слайдером и синхронизированным числовым полем — подгоняется под конкретный
нарисованный/загруженный план), токены персонажей/врагов/массовки/героев.

**Токены и снеппинг к сетке:** во время перетаскивания токен свободно следует за курсором,
а подсветка показывает, к какой клетке он "прилипнет", если отпустить прямо сейчас — токен
всегда встаёт в ближайшую клетку, а не "в угол" клетки сверху-слева.

**Возврат на карту мира** — отдельная кнопка на тулбаре боевой карты.

### Фон боевой карты (см. подробнее раздел 7)

Панель загрузки фона в левом верхнем углу показывает:
- **"Загрузить фон"**, если фона ещё нет вообще, либо **"Заменить фон"**, если уже есть
  кастомный фон для этой конкретной боевой карты;
- подсказку **"Автофон из карточки локации"**, если сейчас показывается изображение из
  Архива, а не кастомный боевой фон — с пояснением, что загрузка своего изображения
  заменит именно боевой фон, не трогая карточку локации;
- кнопку сброса (❌) кастомного фона — возвращает автофон из Архива, если он есть, либо
  просто убирает фон, если его нет.

### Боевой трекер (виджет)

Плавающая панель поверх тактической карты (перетаскивается за шапку, сворачивается).
Показывает всех участников боя с инициативой, HP/AC (редактируются прямо в трекере, не
трогая карточку сущности в Архиве) и свободными текстовыми тегами статусов (яд,
оглушение и т.д. — не привязано к конкретной редакции правил, ГМ вписывает что угодно).

Отдельно в узкой боковой панели (сайдбар) остаётся **старый трекер инициативы**
(`InitiativeTracker`) — упрощённый список порядка ходов, который не заменяется новым
виджетом: это два разных сценария использования, не дубли друг друга.

**Кто участвует в бою:** любой токен персонажа/героя/врага/массовки на активной боевой
карте, размещённый на неё. При старте боя (`startCombat`) все они попадают в список
инициативы с базовыми HP/AC, взятыми из карточки соответствующей сущности в Архиве.

## 7. Связь Архива и тактической карты (фон боя)

Логика приоритета фона тактической карты — единая и предсказуемая:

1. Если ГМ загрузил кастомное изображение специально для этой боевой карты — показывается
   оно.
2. Если кастомного фона нет — автоматически, без единого лишнего действия ГМа,
   показывается изображение из карточки локации в Архиве (то же самое `mapImage`, что
   видно на узле мировой карты).
3. Если нет ни того, ни другого — фон пуст (просто сетка).

Технически кастомный боевой фон хранится **локально в браузере** (IndexedDB), а не в
общем облачном хранилище кампании — это осознанная особенность, а не ограничение: тяжёлые
детализированные боевые карты (сканы, авторские планы подземелий) грузятся и
отображаются мгновенно, без сетевого запроса и без раздувания общего "снапшота"
кампании, который синхронизируется в облако. Расплата за это — кастомный боевой фон не
путешествует на другое устройство ГМа автоматически; изображение из карточки Архива
(автофон) — путешествует всегда, потому что оно живёт в облаке.

## 8. Синхронизация с облаком

Три независимых уровня хранения, которые не стоит путать:

1. **Локальный кэш браузера** — всё состояние кампании (сущности, карта, календарь,
   сюжет и т.д.), работает офлайн, обновляется мгновенно при любом действии.
2. **Локальный кэш тяжёлых изображений боевых карт** — только на этом устройстве (раздел 7).
3. **Облако (Supabase)** — резервная копия кампании для доступа с другого устройства.
   Автосохранение — с небольшой задержкой после последнего изменения (чтобы не слать
   запрос на каждое нажатие клавиши), сравнивается с предыдущим сохранённым состоянием,
   чтобы не писать в облако впустую. Индикатор статуса синхронизации — пилюля в шапке
   (загрузка / ожидание / сохранение / сохранено / ошибка).

   Клик по индикатору с названием мира — принудительно "проталкивает" текущее локальное
   состояние в облако прямо сейчас (не наоборот — это защищает от случайной перезаписи
   несохранённых локальных правок версией из облака).

   Это модель "последняя запись побеждает", без слияния изменений — двух ГМов,
   одновременно правящих одну и ту же кампанию из разных вкладок/устройств, инструмент не
   поддерживает.

   Переименовать кампанию можно прямо здесь же — иконкой карандаша рядом с индикатором.

## 9. Инспектор сущности

Правая выезжающая панель с карточкой выбранной сущности. Ширина панели настраивается
перетаскиванием за левый край (по умолчанию — вдвое шире, чем было раньше) и
запоминается как личная настройка браузера ГМа.

## 10. Режим "ГМ / Игрок"

Переключатель в шапке. В режиме "Игрок" все поля инспектора становятся недоступны для
редактирования одним разом (без необходимости лично блокировать каждое поле в каждой из
форм) — удобно, если экран в моменте показывается игрокам за столом, чтобы случайно не
испортить данные кликом не в то поле. Это тоже личная настройка браузера, а не часть
кампании — не путешествует в облако и не сбрасывается при смене мира.

## 11. Система @упоминаний

В нескольких ключевых текстовых полях (главы сюжета, заметки ГМа в карточке персонажа,
детальное описание локации) работает полноценный текстовый редактор с форматированием
(жирный, курсив, списки и т.д. — через всплывающий тулбар) и **автокомплитом по `@`**:
начинаете вводить `@` и имя — выпадает список подходящих сущностей по всем категориям
сразу (герои, персонажи, массовка, враги, бестиарий, локации, квесты, фракции; секреты
намеренно не участвуют), с иконкой категории для каждого варианта. Стрелки вверх/вниз —
навигация по списку, Enter — выбор, Escape — закрыть список.

Остальные текстовые поля (например, "Краткое описание" в большинстве форм) — обычные
текстовые поля без форматирования и без @упоминаний; это сделано осознанно только для
самых важных полей, расширение на остальные — по мере необходимости.

## 12. Мелкие, но полезные механики

- **Тосты вместо системных окон подтверждения** — удаление сущности, узла карты, других
  необратимых действий не блокирует интерфейс всплывающим `confirm()` браузера, а
  показывает тост с кнопками "Подтвердить"/"Отмена" в углу экрана.
- **Инлайн-переименование кампании** — по иконке карандаша в шапке, Enter — сохранить,
  Escape — отменить и вернуть прежнее название.
- **Автокомплит @упоминаний** — Escape закрывает список без выбора, не прерывая
  редактирование текста.
- **Добавление тега статуса в боевом трекере** — можно ввести текст и нажать Enter, не
  обязательно нажимать кнопку мышью.
- **Добавление черты персонажа в форме персонажа** — аналогично, Enter добавляет черту
  из поля ввода в список.

## 13. Календарь и погода

Текущие день/час кампании — общее "время" на весь мир, продвигается вручную (кнопки
прокрутки времени) или автоматически при перемещении партии между локациями (раздел 5).

Погода привязана к климату кампании (умеренный/зима/пустыня/тропики — у каждого свой
набор возможных условий и базовая температура) и может быть выключена вовсе, если ГМ не
хочет ей пользоваться. Прогноз на несколько дней вперёд можно сгенерировать одной
кнопкой — заново перегенерирует условия на выбранное количество дней начиная с текущего.

**Расписания персонажей:** у персонажей и массовки можно задать расписание (в какие часы
суток кто где находится и чем занят) — при продвижении времени вперёд текущая локация и
занятие персонажа автоматически пересчитываются по этому расписанию (либо возвращаются к
локации "по умолчанию", если для текущего часа ничего не подходит).

## 14. ИИ-генератор

Кнопка "Улучшить/сгенерировать текст ИИ" (значок волшебной палочки) стоит рядом с
основными текстовыми полями большинства форм Архива, а также в отдельном генераторе лута.

**Как формируется контекст для ИИ:** вместо того, чтобы отправлять модели вообще все поля
текущей карточки как есть, приложение собирает урезанный, специфичный для типа поля набор
данных — например, для реплики/описания персонажа в контекст идут только имя, род
занятий, раса/класс, роль, отношение к партии, признак "важный NPC" и цель, но не
расписание или содержимое инвентаря торговца. Это не только экономит длину запроса, но и
не даёт модели "спойлерить" в сгенерированном тексте то, что там быть не должно.

**Атмосфера мира:** в настройках кампании можно задать произвольное текстовое описание
атмосферы/жанра/сеттинга конкретного мира ("тёмное фэнтези с элементами хоррора",
"стимпанк-архипелаг" и т.д.) — оно подмешивается к каждому запросу генерации в этой
кампании. Если поле не заполнено — генератор нейтрален, без какого-либо жанра или
сеттинга по умолчанию.

**Провайдер и модель ИИ** настраиваются в модальном окне настроек — можно указать свой
ключ API (хранится только в этом браузере, в открытом виде — есть предупреждение в
интерфейсе об этом компромиссе) или использовать серверный ключ по умолчанию. Генерация
недоступна без входа в аккаунт.

**Импорт данных через ИИ:** отдельное модальное окно позволяет скачать текстовый шаблон
подсказки (с учётом атмосферы мира), заполнить его вручную любой внешней LLM и вставить
результат обратно — данные разложатся по нужным категориям библиотеки автоматически.

**Генератор лута локации** — отдельная кнопка, генерирующая набор предметов под
конкретную локацию/уровень партии одним запросом.

## 15. Известные ограничения и незавершённые части

- Категория `secrets` пока не имеет своей формы/точки создания в интерфейсе.
- Совместное редактирование одной кампании несколькими ГМами одновременно не
  поддерживается (модель "последняя запись побеждает", без слияния).
- Кастомный боевой фон тактической карты не синхронизируется между устройствами
  (осознанно — раздел 7).
- Старые кампании, сохранённые до объединения категорий `npcs`/`characters` и
  `crowd`/`extras`, могут содержать несмигрированные данные под старыми именами полей —
  для них в шапке появляется отдельная кнопка "Мигрировать данные кампании"; автоматически
  это не происходит.
