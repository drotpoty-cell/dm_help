# GM's Second Brain

Веб-инструмент для мастеров D&D 5e (и совместимых НРИ): интерактивная карта кампании на инфинити-канвасе, библиотека сущностей (герои, NPC, враги, локации, квесты, лут, фракции, события), трекер боя и инициативы, календарь/погода, генерация текста и лута через LLM (Gemini / OpenRouter), автосохранение в Supabase.

Подробная карта архитектуры — в [`PROJECT_MAP.md`](./PROJECT_MAP.md). Она предназначена в первую очередь для ИИ-ассистентов (Claude/Cursor/Cline) и содержит описание слоёв, стора, потоков данных и правил, которых нужно придерживаться при доработке.

## Стек

- **Next.js 16** (App Router) + **React 19**, Turbopack
- **TypeScript**, строгий режим
- **Tailwind CSS 4** — единственный источник стилей (кастомных `.css`-файлов, кроме `globals.css`, нет)
- **Zustand** (со слайсами) — состояние рабочей области кампании, персистентность через `localStorage`
- **Supabase** — авторизация, хранение кампаний (JSONB), Storage для фонов карт
- **reactflow** — инфинити-канвас для карты мира
- **@dnd-kit** — drag-and-drop между библиотекой и картой
- **sonner** — тосты

## Запуск

```bash
npm install
cp .env.local .env.local.local   # или создать .env.local со своими ключами Supabase
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | да | URL проекта Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | да | Публичный anon-ключ Supabase (безопасен для клиента при включённом RLS) |
| `OPENROUTER_API_KEY` | нет | Серверный fallback-ключ для `/api/ai`, если пользователь не ввёл свой ключ в настройках |
| `DEFAULT_AI_PROVIDER` / `DEFAULT_AI_MODEL` | нет | Провайдер/модель по умолчанию (`gemini` / `gemini-2.5-flash`) |
| `GEMINI_PROXY_URL` | нет | Замена базового URL Gemini API (например, для прокси) |
| `NEXT_PUBLIC_SITE_URL` | нет | Используется как `HTTP-Referer` для OpenRouter |

⚠️ `/api/ai` требует авторизованную Supabase-сессию — анонимные запросы отклоняются, чтобы никто посторонний не мог расходовать серверный `OPENROUTER_API_KEY`.

## Известные ограничения / зоны риска

- API-ключ провайдера ИИ, введённый пользователем в настройках, хранится в `localStorage` в открытом виде (BYOK-подход). Это осознанный компромисс: ключ никогда не покидает браузер пользователя, кроме как в теле запроса к собственному `/api/ai`.
- Права доступа к кампаниям (`campaigns`) и файлам фонов карт (`storage/maps`) полагаются на политики Row Level Security в Supabase — их нужно проверять на стороне Supabase-проекта, в этом репозитории они не описаны.
- Сборка использует `next/font/google` — для успешной сборки нужен доступ к `fonts.googleapis.com`. В изолированных/офлайн CI-окружениях это может потребовать самостоятельного хостинга шрифтов.
